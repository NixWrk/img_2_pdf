# Geometry corpus v1

All images and annotations in this directory are deterministically generated by
`scripts/generate_geometry_corpus.py` and are licensed under the repository MIT license. The cases
cover upright/sideways/upside-down layout, small-angle skew, curved and straight text lines, sparse
graphics, a synthetic photograph, and a blank failure case.

Regenerate the corpus:

```powershell
.\.venv\Scripts\python.exe scripts\generate_geometry_corpus.py
```
