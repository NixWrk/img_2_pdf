# UniScan synthetic crop corpus v1

This corpus contains five deterministic, generated scenes: a document, whiteboard,
photograph, book spread, and difficult lighting. `manifest.json` records the exact expected
document corners for each PNG.

All pixels are generated by `scripts/generate_benchmark_corpus.py`; no third-party text,
photographs, logos, or personal data are included. The corpus and generator are distributed
under the repository's MIT license. Re-run the generator only when intentionally publishing a
new corpus version, then review and commit the resulting images and manifest together.

Run the quality benchmark with:

```powershell
uniscan benchmark-quality --input benchmarks/corpus_v1 --output quality-report.json `
  --baseline benchmarks/corpus_v1/baseline.json
```

The redistributable `cv_hybrid` baseline requires all five scenes to crop successfully with no
fallback and a mean corner error below 1% of the image diagonal. Its latency ceiling is
intentionally loose enough for shared CI runners; latency remains visible in every report for
trend analysis.
